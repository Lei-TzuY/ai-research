# AI Research

`ai-research` is the umbrella for a research stack that asks not only whether an AI/ML system runs, but whether its mathematics, implementation, behavior, and evidence can be independently checked.

The planned core layers are:

1. `tiny-transformer-autograd` — mechanism / numerical ground truth;
2. `Quality_Assurance` — validation / trustworthiness methods and evidence models;
3. `iqa-soa` — runtime governance / service-oriented execution and auditable evaluation.

This repository is at **Phase 0 bootstrap**. No source repository is claimed as imported merely because it is listed here. History-preserving migration, source-tree equivalence, source-appropriate CI, attribution review, and explicit executable research contracts are tracked separately.

Research validity is a hard constraint: hypotheses remain hypotheses until supported by pre-specified executable or empirical evidence, and bounded demonstrations are not relabelled as production effectiveness or generalization.
